# Virtual Fashion Stylist

## Project Description
Virtual Fashion Stylist is a Python-based application
developed to help users explore fashion styling options.

## Features
- User Registration
- User Login
- Dashboard
- Outfit Information
- Fashion Styling Interface

## Technologies Used
- Python
- HTML
- CSS
- CSV

## Project Files
- app.py
- main.py
- login_signup.py
- outfits.csv
- static/
- templates/

## Installation
1. Clone this GitHub repository.
2. Open the virtual-fashion-stylist folder.
3. Install the required Python libraries.
4. Run the appropriate Python application entry point.
